# Contributing

Use Node.js 24, `npm ci`, then `npm run check`. Submit focused pull requests with regression tests. Keep source editable and preserve keyboard navigation, reduced-motion behavior, safe error states and content integrity.

Use synthetic fixtures only. Do not copy production photos, backups, storage object names, personal contact data, secrets or account configuration into this repository. Do not add automatic deployment or write-enabled preview workflows without explicit review.

Run `node scripts/privacy-check.mjs` before committing. Preserve third-party notices. Never rewrite a shared branch or force-push without coordination.
